## GitHub handoff

The integration initially rejected repository creation with
`Resource not accessible by integration (createRepository)`. The owner then
created the public `drdanrb/Rstats` repository directly. Push access was
confirmed, and its starter README commit was merged into the project history
before uploading the implementation. No force push is needed.

The source ZIP excludes Git internals and virtual environments. The separate
Git bundle preserves the initial commit/history and can be restored with:

```bash
git clone Rstats.bundle Rstats
```

Public PyPI publication is not performed. `rstats-python` had no matching
distribution on the configured index during implementation, but that check does
not reserve its name. The unrelated `rstats` distribution must not be used as an
installation shortcut.
