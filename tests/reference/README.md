# Independent R reference fixtures

These outputs were generated by **R 4.5.0**, using base R statistics only,
from the checked-in synthetic CSV datasets. Python output is not used as an
expected value. See `R-session.txt` for the actual generating runtime.

From the repository root, regenerate with:

```bash
Rscript tests/reference/generate.R
```

The library and ordinary Python test suite do not require R.

Coverage includes simple/multiple OLS, binary logistic, chi-square independence
and goodness of fit, ordinary ANOVA, ANCOVA, unbalanced factorial Types I/II/III,
Welch, Tukey, Games–Howell, ANCOVA marginal contrasts with Holm/Bonferroni/BH/BY,
one/two-factor repeated ANOVA, mixed ANOVA, and GG epsilon.

- Type I uses R `anova(lm(...))`.
- Type II computes additive-model main-effect SS and full-model interaction SS,
  all tested against the full factorial residual mean square.
- Type III uses `drop1` with sum contrasts and an explicit full term scope.
- Games–Howell uses R's studentized-range distribution and Welch df.
- ANCOVA contrasts use R model matrices and `vcov` at the covariate mean.
- Repeated/mixed F tests use R `aov` with explicit error strata. GG epsilon uses
  covariance projected onto orthonormal within-subject contrasts; mixed epsilon
  removes between-group means before computing the pooled covariance.

Coefficients are aligned by parameter identity because R and Patsy order dummy
columns differently. Floating-point tolerances are tight for linear models and
looser for logistic optimizers and studentized-range numerical integration.
`extended.R` additionally generates Scheffé from base-R F distributions and
Dunnett from the independent **mvtnorm 1.3.3** multivariate-t engine. Regenerate
those with `Rscript tests/reference/extended.R` after installing mvtnorm. See
`R-extended-session.txt`. Dunnett CI inversion/integration uses a looser numerical
tolerance (0.002 absolute/relative); this is not a rounding change to the output.
All ten advertised comparison options have execution/compatibility coverage in
the Python suite.
